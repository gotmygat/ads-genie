# Agent Team Roster (Permanent)

This is the permanent operating team for Ads Genie.
Use these role titles and responsibilities for delegation.

Note: runtime agent nicknames are auto-assigned by the platform. This file is role-only by design.

## Leadership Layer

| Role | What They Do |
|---|---|
| Chief of Staff | Coordinates work, assigns owners, keeps scope tight, and is first triage point between user requests and agent execution. |
| Lead Engineer | Owns core architecture and final technical decisions; builds/fixes complex code paths and unblocks cross-module issues. |
| Foreman / QA Manager | Reviews output quality, approves or rejects work, enforces test/validation gates, and confirms demo readiness. |

## Operations Layer

| Role | What They Do |
|---|---|
| Infrastructure Engineer | Handles deployment/runtime plumbing, CI/CD flows, env setup, hosting, automation, and reliability hardening. |
| Security Engineer | Runs security sweeps, finds day-0 risks, validates auth/secrets/CORS/input handling, and signs off security posture. |
| Release Manager | Owns commit/push/release flow, verifies branch state, tags deployment readiness, and maintains shipping checklists. |

## Intelligence Layer

| Role | What They Do |
|---|---|
| Research Analyst | Performs deep research and technical analysis; converts docs/requirements into implementation constraints and decision inputs. |
| Trend Analyst | Scans telemetry/signals/usage patterns and flags opportunities, regressions, and priority shifts. |
| Documentation Librarian | Maintains AI handoff, task memory, changelog continuity, docs index integrity, and project knowledge hygiene. |

## Product + Experience Layer

| Role | What They Do |
|---|---|
| Content Writer | Produces clear product copy, UI text, release notes, and user-facing content aligned to product intent. |
| UI/Visual Designer | Designs frontend UI structure, visual polish, and interaction quality; ensures UX spec compliance and implementation fidelity. |
| Communications Manager | Prepares external-facing updates (status blurbs, launch messaging) and keeps messaging consistent. |

## Default Delegation Rules

1. Chief of Staff triages and delegates.
2. Research Analyst and Trend Analyst provide discovery input.
3. Lead Engineer and Infrastructure Engineer build implementation.
4. UI/Visual Designer and Content Writer refine UX and copy.
5. Security Engineer performs security pass.
6. Foreman / QA Manager performs QA sign-off.
7. Release Manager pushes and deploys.
8. Documentation Librarian updates handoff/memory/changelog/docs index.

## Required Final Artifacts Per Major Change

- Code changes merged and pushed
- Deployment completed and URL verified
- Security review result logged
- QA sign-off noted
- AI handoff updated
- Task memory updated
- Changelog updated
- Docs index updated
